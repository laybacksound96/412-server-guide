게임 업데이트

Project Zomboid 게임 자체의 패치 요약. 서버 쪽 변경은 위키 업데이트 내역에 있음.

42.22.2 안정판 2026-11-09 공개

이 서버에 언제 적용될지는 아직 정해지지 않음. 정해지면 위키 업데이트 내역에 알림.

  • 새 기능: 사다리 사용, 쇠지렛대로 잠긴 문·창문 강제로 열기, 라이터에 휘발유 다시 채우기(깔때기 필요), 너구리 두개골로 동물 두개골 목걸이 제작
  • 악취 무들이 있으면 잠을 잘 수 없음 (이유가 툴팁으로 표시)
  • 양손에 무거운 물건이나 손전등을 들고 있을 때 넘어지면 주무기 쪽을 떨어뜨림
  • 걸으면서 할 수 있는 동작 추가: 우산 펴기·접기, 옷·시트 찢기, 탄약 상자 열기, 배터리·프로판 통 넣고 빼기, 양초·랜턴 끄기, 담배를 갑에 넣고 빼기
  • 손전등 렌즈에 켜짐/꺼짐이 보이게 바뀜, 직접 만든 무전기·워키토키의 무게가 고정값으로 바뀜, 금속 톱질 레시피 정리
  • 멀티플레이: 피해 계산이 서버로 옮겨짐, 캐릭터가 청크 경계에서 "분신"처럼 복제되던 문제 수정, 치트 방지 강화, 서버 백업 속도 개선, 트레일러 물리·견인 동기화 수정, 재접속 뒤 움직이던 차량이 사라지던 문제 수정, "지도 미리 공개" 설정이 멀티에서 안 되던 문제 수정, "지도 불러오는 중"에서 멈추던 문제 수정
  • 기타 수정: 차 근처에 열쇠가 저절로 생기던 문제, 열쇠 없이 안에서 바깥문을 잠글 수 없던 문제, 앨리스 벨트·체스트 리그가 탄창 장전을 빠르게 하지 않던 문제, 토스터·커피머신이 전기 없이 작동하던 문제, 일부 울타리 모서리를 넘을 수 없던 문제, 동물이 사라지거나 죽던 문제 여럿
  • 소리: 무기·투척물 장착 소리, 사다리 발소리 등 새 효과음 다수
  • 모드 제작: 맵 모드에 마을 미리보기 영상 추가 가능

요약만 옮김. 전체 내용은 Steam 패치노트 원문에서.
