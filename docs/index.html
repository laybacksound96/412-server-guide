처음 접속하면 모드 230여 개를 내려받아서 오래 걸림. Steam 모음집을 미리 구독해 두면 빠름.

접속 전 준비 — 게임 메모리 늘리기

모드가 많아서 기본 메모리(3GB)로는 끊기거나 메모리 부족으로 꺼질 수 있음.

  1. 게임 종료 후 C:\Program Files (x86)\Steam\steamapps\common\ProjectZomboid\ProjectZomboid64.json을 메모장으로 엶
  2. "-Xmx3072m"을 찾아 RAM 16GB면 "-Xmx6144m", 32GB 이상이면 "-Xmx8192m"으로 바꿈
  3. 저장 후 게임 실행. 게임 업데이트 뒤 원래 값으로 돌아갈 수 있으니 다시 끊기면 이 값부터 확인

서버 규칙

공용 목숨

  • 서버 전체가 목숨 5개를 함께 씀. 누가 죽든 1개씩 줄어듦 (동물은 제외)
  • 게임 시간 매일 자정에 화면 가운데 Lives: 남은 목숨이 표시됨
  • 목숨이 0이 되면 월드가 초기화됨 (맵, 캐릭터, 시체, 차량 전부). 서버는 새 월드로 자동 재시작됨
  • 새 캐릭터로 다시 시작해도 목숨은 돌아오지 않음

시간

  • 게임 하루 = 현실 30분
  • 접속자가 아무도 없으면 시간이 멈춤 (음식 부패, 작물, 호드 일정 모두 정지)

좀비

  • 이동 속도 무작위: 느린 걸음·빠른 걸음이 섞이고, 일부는 뛰어다님
  • 지능 무작위: 일부는 문을 열 수 있음. 문을 닫아 두는 것만으로는 안전하지 않음
  • 감염: 혈액과 타액, 증상 발현 1~2주, 사망 후 좀비화 1~2주

호드 (Dynamic Horde Events)

종류규모
일반 호드5~30마리 (생존 일수에 따라 최대 1.5배)
떠도는 호드40~120마리
대재앙 호드200~500마리

캐릭터 생성

  • 직업·특성 주사위(Destiny Dice): 주사위를 굴려서 랜덤 직업, 특성을 고를 수 있음
  • 스폰 지역: 무작위 실내 스폰, 바닐라 4곳(멀드로, 웨스트 포인트, 로즈우드, 리버사이드), 추가 맵 9곳

알아 두면 좋은 기능

  • 업적: 원형 메뉴(Q) → 업적. 목표를 달성하면 캐릭터 보너스
  • 제작 화면: 레시피 정보 창에 출처 모드가 "모드: 이름"으로 표시됨
  • KI5 차량: 차마다 전용 정비 지침서를 읽어야 차체 부품 제작 가능. 장갑·범퍼·불바는 금속 용접으로 제작
  • 모드별 자세한 설명은 모드 가이드에서 검색

문제 해결

증상해결
접속 후 1분 안에 튕김, "File doesn't exist on the client" 또는 체크섬 오류모드 버전이 서버와 다름. 게임을 끄고 Steam 다운로드 화면에서 업데이트 완료 대기 → 안 되면 해당 모드 구독 취소 후 재구독
몇 초마다 끊김, 메모리 부족으로 꺼짐위 "게임 메모리 늘리기" 적용, 그래픽 설정에서 텍스처 품질 낮추기
